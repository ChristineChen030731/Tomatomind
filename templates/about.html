ℹ️ About TomatoMind

Learn about this project, the technology stack, and the dataset.

🎯 Project Overview

TomatoMind is an intelligent movie analytics web application built on the Rotten Tomatoes dataset. It combines machine learning and data visualization to provide:

  • Sentiment Analysis — Classify movie reviews as Positive or Negative using NLP
  • Movie Recommendation — Discover similar movies via collaborative filtering
  • Data Dashboard — Interactive charts exploring movie trends
🔧 Technology Stack
Backend
  • Python — Core language
  • Flask — Web framework & REST API
  • Pandas & NumPy — Data processing
  • Scikit-learn — Machine learning (TF-IDF + Logistic Regression)
Frontend
  • HTML5 + CSS3 — Page structure & styling
  • Bootstrap 5 — Responsive UI framework
  • Chart.js — Interactive data charts
  • JavaScript (Vanilla) — Client-side logic
🧠 Models
Sentiment Model
  • TF-IDF vectorization (5000 features)
  • Logistic Regression classifier
  • Binary: Fresh → Positive, Rotten → Negative
  • Training data: 100K sampled reviews
Recommendation Model
  • Item-based Collaborative Filtering
  • Cosine similarity between movies
  • User-item matrix from critic reviews
  • Filters cold-start users & movies (< 5 reviews)
📦 Dataset

The Rotten Tomatoes dataset from Kaggle contains:

Movies17,713
Critic Reviews1,130,017
Fresh Reviews~700K
Rotten Reviews~400K
Top Critics~115K reviews
📋 Course Info

This project was built as a course assignment demonstrating full-stack web development with machine learning integration.

System Architecture: Data Layer → Model Layer → API Layer → Web Layer → User
